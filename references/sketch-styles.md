# 手绘画风菜单（SK 管线）

图库：`templates/sketch/styles/preview/menu.html`，A–G 各有一张参考帧。A–E 的短视频样片不进 Git；需要时从 `styles/<画风>.html` 本地渲染。

**新系列第一期，先把 `menu.html` 给项目负责人看，选 2–3 种；再用这期最关键的一句口播，按挑中的画风各渲一帧（G2 闸门），方向确认后再开工。** 已有系列沿用 `look/CHOSEN.md` 里记的那一种。

A–E 走 SK 管线（`kit/sk.js`），**换画风只改一行**：

```js
SK.page(document.getElementById('sv'), {style:'kraft'});   // pencil | journal | kraft | mono | chalk
// 可选：{style:'journal', accents:['#F6C85F','#8FD3B6','#F4A6A6','#8DB8E8']}，或 {accent:'#07C160'} 只换第一重音色
```

前提：画面要用 `SK.shape / SK.line / SK.text / LDD.create` 画，颜色从 `SK.C[i]`、`SK.INK`、`SK.PAPER` 取，不要把色值写死在 SVG 里。参考写法：`templates/sketch/styles/<画风>.html`，五个文件只有 `STYLE` 那一行不一样。老的 7 个参考镜头（`templates/sketch/shots/`）是写死铅笔色的，只适合 A。

F、G 是 HyperFrames + House kit 那套，做法见 `animation.md` / `house-style.md`，参考镜头在 `templates/shots/`。

## A 铅笔素描本 `pencil`
点阵本 + 线圈、石墨线带颗粒、手写体（Hannotate SC），灰色排线做阴影，只有一种重音色（默认鲜绿 `#07C160`）。
- 适合：推导、步骤、关系；默认基线风格，轻松亲和
- 人物：线身体火柴人
- 重音色每镜 2–4 处，不要满屏

## B 手账平涂 `journal`
暖白点阵纸、炭灰圆润线（几乎不抖）、莫兰迪平涂（黄 / 薄荷 / 粉 / 蓝）、卡片带一道硬投影、圆体字（阿里妈妈方圆体 → 圆体 → 苹方）。
- 适合：清单、对比、"三件事"、工作方法；信息多也不乱
- 人物：**色块身体**的简笔人（圆头 + 粉色圆角矩形身体 + 线胳膊线腿），可以加机器人、小动物这类符号角色
- 颜色：一屏最多三种填充色；文字只用炭灰；不要整片铺彩色底
- 容易翻车：做成 PPT 卡片墙。一屏一张主卡，周围留白 ≥ 40%

## C 牛皮纸涂鸦 `kraft`
米黄卡纸 + 纤维噪点、深褐粗线明显抖动、**色块故意错开轮廓露白**（`fill:'offset'`，往右上偏 9/7px）、手写体。重音：土黄、砖红、灰绿。
- 适合：历史、故事、"从前是这样的"、生活类话题，温暖、有手作感
- 人物：线身体火柴人，也可以只用圆头 + 两根线当符号（远景里的人）
- 容易翻车：错位太大像印错版。偏移别超过 12px，同一屏统一方向

## D 单色圆角 `mono`
奶油底 + 轻暗角、单一焦糖棕、粗圆角线、**完全不抖**、实心填充从中心长出来、圆体字。
- 适合：产品、品牌、"一个东西变成另一个东西"
- **必须配变形**：上一个图形直接变成下一个（液体倒出来变成字、圆点变成文件），不靠变形撑着，就是这七种里最像程序图的一种
- 人物：尽量少用；要用就是不抖的线身体火柴人

## E 黑板粉笔 `chalk`
墨绿黑板 + 擦痕、粉笔白线带颗粒、粉笔排线上色（黄 / 粉 / 薄荷）、手写体。
- 适合：讲原理、公式、"上课"感的速通类内容
- 注意：排线会盖住文字，**字不要写在有排线的色块上**，写在旁边
- 跟真人口播切换时明暗反差大，整期都用它，别跟浅色画风混

## F 剪纸拼贴（House kit）
撕边纸片 + 投影 + 纸纹，满幅墙色，角色有简单的脸。适合比喻多、有"角色"的扫盲片。参考 `templates/shots/paper-manual.html`。

## G 资料拼贴（House kit）
真截图 / 文档当剪报，荧光笔、胶带、轻颗粒。适合真数字、真截图、真新闻为主的段落。参考 `templates/shots/dossier-doc.html`。

## 人物和道具：不只是火柴人

kit 里的 `LDD.create` 会跟着画风变：A/C/D/E 是线身体，B 是色块身体（`body:'block'`，颜色 `color:SK.C[2]`）。要别的样子，可以让模型**自己用 SVG 路径画**：机器人、猫、穿色块衣服的小人、电脑、咖啡杯都行，条件是：

1. **同一支笔**：线宽、线色、抖动滤镜（`url(#pencil)` / `url(#pen)`）、填色方式都和这个画风的预设一样。最稳的写法是直接用 `SK.shape(parent, d, {fill:SK.C[i]})`，它会自动按画风上色
2. **是矢量路径，不是贴图**：不拿人物插画 PNG 拼代码画的胳膊（那样画法对不上，手会很吓人）
3. **符号化，不写实**：不画具体项目中的真人肖像或专属 IP 形象。角色特征用一两种通用符号表达：帽子、色块身体、眼镜等
4. **要动的胳膊仍然用 IK 两段式**（`kit/stick.js` 的写法），肘看得见，A11 手臂检查照做
5. 一屏最多 3 个角色，主角比配角大

## 换画风时一起变的东西

| | 纸 | 线 | 抖动 | 填色 | 字体 |
|---|---|---|---|---|---|
| pencil | `#F6F3EA` 点阵 + 线圈 | `#34322E` 5px | 有，带颗粒 | 排线 | Hannotate SC |
| journal | `#FBF7EF` 点阵 | `#2E2C2A` 4.5px | 很轻 | 平涂 + 硬投影 | 阿里妈妈方圆体 / 圆体 |
| kraft | `#F1E8D5` 纤维 | `#4A4235` 6px | 明显 | 错位露白 | Hannotate SC |
| mono | `#F2E9DE` 暗角 | `#5A3A26` 8px | 无 | 实心，从中心长出 | 阿里妈妈方圆体 / 圆体 |
| chalk | `#232C29` 擦痕 | `#ECEAE2` 5px | 有，带颗粒 | 粉笔排线 | Hannotate SC |

字体换机器先查：`fc-list | grep -iE "Hannotate|FangYuan|Yuanti"`，缺了就按表里的顺序往后退。

A8 照旧适用于所有画风：不要章节小标签、来源角标、装饰短横线、色块标签胶囊。
