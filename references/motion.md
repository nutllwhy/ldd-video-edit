# 动作规则

## 时长（30fps）

| 元素 | 时长 |
|---|---|
| 小图标、标签弹出 | 0.15–0.25 s |
| 卡片入场 | 0.25–0.35 s |
| 卡片退场 | 入场的 65–75% |
| 大物件移动 / 转场 | 0.4–0.6 s |
| 重点揭示 | 0.6–1.2 s |
| 环境动态（呼吸、漂浮） | 2–20 s 循环，幅度只有 10–20% |

移动距离越远时间越长：移动 100px 是 1×，300px 约 1.5×，横穿全屏约 1.8–2×。

## 缓动

- 入场用 ease-out，退场用 ease-in，在画面里移动用 ease-in-out，循环用 sine，空间移动**不许用 linear**
- 大物件（角色、书、窗口）用弹簧：刚度 250–350、阻尼 18–24；UI 元素允许 3–5% 的过冲，大字不过冲
- 一个值要连续变好几次的，每次换目标都接着上一次的速度走，不要每次重新起一条缓动
- 全片至少用两三种动作个性，主要动作和次要动作的缓动要不一样

## 层次
- 主要动作之外加次要动作：影子跟着动、子元素晚 50–150ms 跟上、角色有反应
- 几个元素同时入场时错开 50–100ms，总共不超过 0.5 s
- 同一时刻只有一个主角在动，其余压暗或者静止
- 前、中、后三层视差，后景移动速度是前景的 0.3–0.5

## 镜头
- 镜头的意思是"把世界里的某一点放到屏幕上的某一点"，不要绕画面中心缩放，否则主体会掉到字幕带里
- 每个 C 镜头里，镜头自己至少动一次：推、拉、摇，或者一个切镜
- 推镜要推到一个具体的东西上（一行字、一只手、一个按钮）
- 景别全片要有变化，每期至少一个大特写

## 镜头动作表（动之前先问：观众这一刻该看哪；这是过渡还是重音；上一个动作是什么）

| 动作 | 时长与形状 | 用在 |
|---|---|---|
| 停住 | — | 画面自己在动，或观众在读字 |
| 缓推 | 0.6–1.5 s，sineInOut，推近 10–40% | 过渡，看向下一件事 |
| 拉远 | 0.8–2 s，长尾缓动 | 收束，看全貌 |
| 横移 | 0.5–0.9 s | 找下一个东西 |
| 快推 | 0.25–0.35 s，推近 18–32% | 揭晓、关键数字 |
| 甩镜 | 0.26–0.30 s + 运动模糊 | 换话题 |
| 砸入 | 0.17 s，1.55→0.94→1.0，每镜最多一次 | 最重的一下 |
| 硬切 / 跳近 | 0 帧 | 句读处 |

- 重音动作（快推、甩镜、砸入）不超过全部镜头的 1/3
- 不要连着三次往里推；推进去之后拉出来或横移开。每分钟推近超过 8 次就太多了
- 匀速慢漂（1–4%/s）只给氛围镜头，解说镜头每镜都漂就是 PPT

## 节奏
- 每 2–4 秒画面必须有新东西：一个动作、一次揭示、一次切镜、一个反应
- 硬切要切在画好的画面上：新镜头的第一帧就是完整的，不要切过去还是空的再慢慢长出来
- 这一步之前就存在的东西，从第 0 帧就在画面里；只有这一步带来的变化才做动画
- 手绘、剪纸、像素这类风格用一拍二（每个姿势停 2 帧），线条每 2 帧轻微抖一下
- 平滑矢量风格可以一拍一，但要加一点运动模糊

## 转场
- 段落之间的转场跟着内容走：把上一个世界收进一个物体，这个物体变成下一个世界里对应的东西，再从它展开（比如手册合上变成工具箱）
- 一期里这种形变转场最多用三四次，其余用硬切
- 硬切落在说话的停顿上
