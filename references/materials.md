# 素材处理

## 先盘点
接手文件夹先列一张表（`work/素材.md`）：文件名 / 分辨率 / 时长 / 横竖 / 有没有烧录字幕 / 有没有平台或敏感信息 / 打算放在哪一句。
- `ffprobe` 看规格；每条视频抽 3 帧看内容
- 口播素材如果有多遍（同一段连导几次、带黑边的版本），用音频互相关对齐，确认用哪一遍、偏移多少

## 原样放，不加料
- 不在素材上叠暗角、渐变、色调、颗粒（M1）。需要压字幕的地方，用字幕自己的描边和底框解决
- 素材自带烧录字幕的：按比例放大，把字幕推出画面（例：`scale 1.34, transform-origin 50% 0%`）；推不掉就换片段

## logo（M3）
1. **找当前官方版本**，按优先级：
   - 本机装了这个 App：从 `.app/Contents/Resources/*.icns` 导出 1024 px
   - 官网 / 应用商店的 512–1024 px 透明 PNG 或 SVG（导航栏、favicon 只是备选，往往太小或带底色）
   - SVG 用无头 Chrome 渲透明底：`--default-background-color=00000000`
2. 图标和字标连在一张图上的（导航栏那种横条），先把图标那一段裁出来
3. `python3 $SK/scripts/logo_norm.py out_dir a.png b.png …`：抠掉纯色底，按透明区域裁边，统一放进 512×512 画布，内容占 94%，出 `sheet.png` 对比
4. 看 `sheet.png`：几个 logo 的**视觉面积**一样大才算过。圆形、带大量留白的标会显小，单独放大；方形满版的标显大，缩到 0.88 左右
5. 排法：logo 在上、名字在下，同一行等距；不加白卡片，深色底上加一点投影
6. 放大到 400% 看边缘：没有白边、锯齿

## 截图与录屏
- 裁掉：浏览器标签栏、系统菜单栏、设备名、头像、输入框里的模型版本号
- 模糊：甲方名、客户名、私人信息
- 录屏里出现无关的第三方工具名也裁掉
- 网页长图在动画里当"打印件"用，不做滚动长截屏

## 敏感信息（M4）
邀请码、优惠码、二维码：一个深色半透明小胶囊（"邀请码 XXXX"，字号 28/40），放左上角，弹出一下就停住，底下照常放素材。不要做成主画面。

## 数字（M6）
画面上出现的每个数字，在 `plan.md` 里写出处（原文页码、官网链接、截图）。查不到的不放。示意性的图表用线和形状，不写数。
