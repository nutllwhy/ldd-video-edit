# Style sample review (G2)

Do not render a full batch of animation before the visual direction is approved.

## Prepare the sample

1. Choose a key shot that represents the content and the hardest visual problem.
2. For a new series, show a range of distinct directions from `references/sketch-styles.md`. If a visual reference was supplied, include one interpretation of it.
3. Render real frames with the same technique planned for the final animation. A generated moodboard may help discuss direction, but it is not a substitute for a pipeline-accurate sample.
4. Compare samples at delivery size. Check medium, palette, typography, composition, camera, and motion—not merely the color.
5. Build a clearly labeled comparison sheet; keep labels outside the sample frames.
6. Explain each direction in terms of fit, production effort, and how it will transition to the source footage.

## Record the decision

Store the chosen direction and any requested adjustments in the project workspace. Revise the sample if needed, then use the approved sample as the starting point for the animation system. Do not copy private quotations or client-specific notes into this public skill repository.

## Existing series

A series can keep its established medium, but still produce a representative frame for each new episode. The content changes, so confirm that the chosen visual approach remains suitable.
