# Choosing a motion-graphics approach

Decide **how** the idea is shown (camera, pacing, sequence) separately from **what visual medium** it uses (line, fill, texture, palette, typography). A project may use several presentation methods, but each shot should have one clear focal point and a coherent medium.

## Choose an approach for the content

| What the narration is doing | Approach | Typical duration | Visual principle |
|---|---|---:|---|
| Explaining an abstract mechanism | Flat explainer | 7–9 s | Turn the idea into a concrete object or small world; let it change at narration beats. |
| Showing one concept becoming another | Shape transformation | 1–3 s per action | Morph the previous visual into the next rather than cutting between unrelated diagrams. |
| Presenting authentic evidence | Editorial / dossier collage | 3–7 s per source | Arrange real source material as printed artifacts; move the camera to guide attention. |
| Telling a personal anecdote or joke | Simple visual story | Around 2–3 s | Use a clear pose, hold for the reaction, and cut on the beat. |
| Introducing a short list or key phrase | Kinetic typography | Around 2 s | Put the key phrase on a meaningful object or surface; avoid generic title cards. |
| Demonstrating a tool or interface | Interface-led | 5–8 s | Let the real interface dominate; crop or zoom to the relevant control. |
| Comparing verified quantities | Data visualization | 2.5–6 s | Reveal only the comparison needed to support the point. |
| Reasoning through steps | Whiteboard / sketch | 6–7 s | Draw one part at a time and let the camera follow the argument. |

## Motion principles

1. Move the camera only when attention should move. Prefer a restrained push, pan, or pull-back; reserve rapid moves for reveals.
2. If every shot uses the same movement, the result still feels like a slide deck. Vary the visual action as well as the camera.
3. Layer smooth camera motion with stepped element animation when it suits the medium.
4. Anchor large text and numbers to a physical object or surface instead of placing them on an empty card.
5. Keep one focal point per frame. Supporting text should be visibly subordinate.
6. Use real source footage as the main visual when evidence or product behavior matters; use code for framing, emphasis, and motion.
7. Put transitions at breaths or topic changes, not in the middle of an unfinished phrase.
