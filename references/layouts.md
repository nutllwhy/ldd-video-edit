# 版式

两种画幅，各自一套固定版式。尺寸是实际交付过的片子里调好的，没有理由不要改。

## 横屏 4:3（1440×1080）

拼接用 `scripts/assemble.py`。

| 代号 | 画面 | 参数 |
|---|---|---|
| A 露脸 | 口播铺满 | 16:9 原片从中间裁成 4:3（`prep.sh`） |
| B 叠加 | 口播 + 一个元素 | 元素放在边缘或上下三分之一，不压脸 |
| P 画中画 | 右上卡片 + 左下圆形人像 | 卡片 1094×821 放 (306, 40)，圆角 22；人像直径 240 放 (40, 621)，4px 描边；`face_crop` 取以脸为中心、边长约头高 1.2 倍的正方形 |
| C 全屏动画 | 动画铺满 | |

字幕带 y 940–1040。P 和 A 相邻时 0.2 秒淡入淡出，其余硬切。

## 竖屏 9:16（1080×1920）

拼接用 `scripts/assemble_vertical.py`，素材准备用 `scripts/vertical_prep.sh`。字幕需要 CJK 字体；可用 `LDD_CJK_FONT` 指定字体文件，未指定时脚本尝试使用系统字体。

| 代号 | 名字 | 什么时候用 | 画面 |
|---|---|---|---|
| **VA** | 全屏真人 | 第一句、情绪点（"别怕"）、号召、结尾 | 口播从 4:3/16:9 原片中间裁 9:16 铺满。字幕居中，y≈1430 |
| **VS** | 全屏素材 + 圆头像 | 9:16 的成片案例、竖屏录屏、全屏 MG 动画 | 素材铺满；左下圆形头像；字幕在头像右侧，多行左对齐 |
| **VH** | 1:1 分屏 | **横屏素材**：电脑录屏、网页、横屏成片 | 上半屏 1080×840 放素材，下半屏 1080×1080 放方形真人（y 840 起），字幕居中压在接缝 y=840 上 |

### VS 圆形头像
- 直径 310，左上角在 (44, 1250)；外面 6px 白圈 + 向下的软阴影
- **取景**：肩膀以上、头顶留白、人在圆里**缩小居中**。脸贴边就是取景错了，不是圆太小
- 如果项目提供了"圆形蒙版"专用素材（黑底、人已在圆里摆好）时，直接从那条素材裁出圆的外接正方形：`vertical_prep.sh` 的第 3 个参数。圆再往里收 1.2%，去掉黑边
- 字幕在圆右边：x 从 380 开始，右边不超过 940

### VH 分屏
- 上半屏素材的处理：
  - 录屏/网页：裁掉浏览器顶栏和系统 chrome，按宽铺满 1080，必要时加一个窗口框（交通灯）
  - 比例接近 1:1 的素材：用同一素材模糊放大做底，前景按高缩到 800 居中
- 下半屏：口播原片取 1:1 正方形，人居中、头顶留白
- 不配圆头像

### 安全区
- 内容 y 200–1680；右侧 x > 940 是平台按钮区，字和重要信息不进去
- 邀请码这类小信息放左上 (44, 200) 附近

### 版式切换
一律硬切。VA ↔ VS ↔ VH 之间不做转场；同一版式里连着几段素材，圆头像不消失。
