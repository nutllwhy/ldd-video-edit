# 版式

两种画幅，各自一套固定版式。尺寸是实际交付过的片子里调好的，没有理由不要改。

## 横屏 4:3（1440×1080）

拼接用 `scripts/assemble.py`。

| 代号 | 画面 | 参数 |
|---|---|---|
| A 露脸 | 口播铺满 | 16:9 原片从中间裁成 4:3（`prep.sh`） |
| B 叠加 | 口播 + 一个元素 | 元素放在边缘或上下三分之一，不压脸 |
| P 画中画 | 右上卡片 + 左下圆形人像 | 卡片 1094×821 放 (306, 40)，圆角 22；人像直径 240 放 (40, 621)，4px 描边；`face_crop` 取以脸为中心、边长约头高 1.2 倍的正方形 |
| C 全屏动画 | 动画铺满 | |

| K 抠像 | 素材卡铺满 + 抠像人物叠在左下角 | 见下方「抠像版式」，`scripts/cutout_compose.py` 生成，进 `assemble.py` 时 mode 用 `cover` |

字幕带 y 940–1040。P 和 A 相邻时 0.2 秒淡入淡出，其余硬切。

## 竖屏 9:16（1080×1920）

拼接用 `scripts/assemble_vertical.py`，素材准备用 `scripts/vertical_prep.sh`。字幕需要 CJK 字体；可用 `LDD_CJK_FONT` 指定字体文件，未指定时脚本尝试使用系统字体。

| 代号 | 名字 | 什么时候用 | 画面 |
|---|---|---|---|
| **VA** | 全屏真人 | 第一句、情绪点（"别怕"）、号召、结尾 | 口播从 4:3/16:9 原片中间裁 9:16 铺满。字幕居中，y≈1430 |
| **VS** | 全屏素材 + 圆头像 | 9:16 的成片案例、竖屏录屏、全屏 MG 动画 | 素材铺满；左下圆形头像；字幕在头像右侧，多行左对齐 |
| **VK** | 抠像 + 素材卡 | 讲录屏、网页、文档时想要前后层次 | 素材卡在上，抠出来的人在下方偏左，背后一块磨砂面板；`scripts/cutout_compose.py` 生成，进 `assemble_vertical.py` 时 mode 用 `bare` |
| **VH** | 1:1 分屏 | **只给操作界面**：电脑录屏、网页、App 界面。普通生成图、产品图不要分屏 | 上半屏 1080×840 放素材，下半屏 1080×1080 放方形真人（y 840 起），各占一半，字幕在接缝下方、头顶上方 y≈975 |
| **VG** | 磨砂居中 | 生成图、效果图、产品图——一条片里最常用的默认版式 | 素材**整张**不裁，按高缩到约 1180–1300 居中；背景是同一张图放大铺满、高斯模糊、压暗（见下方「磨砂背景」） |
| **VC** | 全屏视频 + 参考图小卡 | 图生视频、动效演示 | 视频全屏；左下角一张参考图小卡（约 300 宽，圆角 16，2px 淡白描边）；**不放脸** |
| **VQ** | 四宫格 | 开场悬念段（"哪张是实拍"这类对比） | 四张图 2×2 铺满，格间 8px；揭晓之后再出现小头像 |

### 按段落选版式（效果展示类）

| 段落 | 版式 |
|---|---|
| 开场悬念（让观众猜） | VQ，揭晓时才进 VS / VG |
| 生成图对比、效果细节 | VG，一张一张来，整张不裁 |
| 图生视频、动效 | VC |
| "几毛钱一张"这类强调句、结尾互动 | VA 全屏真人 + 花字 |

整条片子里人露脸的时间是少数，别让大头像把素材挤小（rules L12）。

### 磨砂背景（VG / 全屏真人）

同一张图放大铺满 → `gblur=sigma=60` → 压暗一点（`brightness=-0.32`），前景素材原样居中盖上去。这样前景不用裁、也有前后层次。前景要清晰，背景只需要认得出来是同一张图。

### VS 圆形头像
- 直径 310，左上角在 (44, 1250)；外面 6px 白圈 + 向下的软阴影
- **取景**：肩膀以上、人在圆里**缩小居中**；从宽画布里裁脸时往中间取，脸多露一点，头顶留白少一点（rules L14）。脸贴边就是取景错了，不是圆太小
- 如果项目提供了"圆形蒙版"专用素材（黑底、人已在圆里摆好）时，直接从那条素材裁出圆的外接正方形：`vertical_prep.sh` 的第 3 个参数。圆再往里收 1.2%，去掉黑边
- 字幕在圆右边：x 从 380 开始，右边不超过 940

### VH 分屏
- 上半屏素材的处理：
  - 录屏/网页：裁掉浏览器顶栏和系统 chrome，按宽铺满 1080，必要时加一个窗口框（交通灯）
  - 比例接近 1:1 的素材：用同一素材模糊放大做底，前景按高缩到 800 居中
- 下半屏：口播原片取 1:1 正方形，人居中、头顶留白
- 不配圆头像

### 安全区
- 内容 y 200–1680；右侧 x > 940 是平台按钮区，字和重要信息不进去
- 邀请码这类小信息放左上 (44, 200) 附近
- 字幕放在安全区偏上的位置：中心 y≈1480（离底边约 440）。脚本默认 `subs_y` 是 1430，两个都在安全区内；不要再往下压到 1600 以下，发布平台底部的界面会盖住字幕

### 字幕跟着版式走

一句话说到一半换了版式，字幕也要拆：画面切的那一帧字幕换到新位置（rules E5）。各版式的字幕位置：

| 版式 | 字幕位置 |
|---|---|
| VA 全屏真人 | 居中，y≈1480（胸口） |
| VG 磨砂居中 | 居中，y≈1480 |
| VH 分屏 | 接缝正下方、头顶上方，y≈975 |
| VS 圆头像 | 头像右侧，左对齐，x 从 380 起 |
| VC 参考图小卡 | 小卡右侧 |
| VK 抠像 | 脚本打印的 `subs_y` |

### 版式切换
一律硬切。VA ↔ VS ↔ VH 之间不做转场；同一版式里连着几段素材，圆头像不消失。

## 抠像版式（VK 竖屏 / K 横屏）

把口播里的人抠出来、加一圈贴纸描边，叠在素材卡前面，背后垫一块磨砂面板，顶部可选章节条。一条命令出一段无字幕的画面：

```bash
python3 "$SK/scripts/cutout_compose.py" <project>/edit/cutout-01.json
```

配置字段见脚本开头的说明。脚本结束时打印这一段的字幕位置，照抄进剪辑表那条 clip：竖屏写 `"subs_y"`，横屏写 `"subs_shift"`。

| | VK 竖屏 1080×1920 | K 横屏 1440×1080 |
|---|---|---|
| 章节条 | 顶部 0–180 | 顶部 0–144 |
| 素材卡 | 宽 1000，左上 (40, 190)，圆角 22；没有章节条时 y=120 | 宽 1360，左上 (40, 150)，圆角 20，素材是画面主体 |
| 磨砂面板 | (32, 1000)–(1048, 1888)，圆角 44 | 不垫面板：人直接叠在素材卡上，靠描边 + 向下的软投影分层 |
| 人物 | 820 见方，脸在画面宽 28% 处，头顶 y≈1170，只露到胸口 | 540 见方，叠在卡片左下角，脸在画面宽 14% 处，头顶 y≈560；会挡住素材左下一角，素材的关键内容不要放在那里 |
| 字幕 | 卡片和面板之间（约 y 864） | 卡片下沿以下、人物右侧，单行不超过约 870px |

做法和取舍：
- **抠像**：macOS 14+ 的 Vision 主体分割（`scripts/cutout/fg_mask.swift`，第一次运行自动编译）。它会把手里拿的道具一起保留，比纯人像分割干净。连续三帧加权平滑，压住边缘抖动；粗剪的跳剪点上蒙版会跟着跳，这是正常的。
- **描边**：先把蒙版收边，去掉发丝里残留的原背景色，再圆角外扩。默认奶白 `#F5F5F2`、11px，可改颜色。细碎发丝会被收掉一点，整体读起来像贴纸。
- **人的大小**：人别太大。露到胸口、偏到一侧，右边留给手势和字幕。站位按蒙版自动量头顶和脸的位置，换素材不用手调；要改就写 `person.size / face_x / top`。
- **横屏为什么不垫面板**：横屏里素材要占大头，人叠在素材上更紧凑；再垫一块面板会把素材挤小。
- **磨砂面板**（竖屏）：用素材本身轻度模糊（sigma 18）、略压暗、叠 10% 白，再加一圈 2px 淡白边。糊得太重会变成一块灰板，要能隐约看到后面的内容。整个底层是同一素材的重度模糊（sigma 60）加压暗。
- **章节条**：`scripts/chapter_bar.py`，等宽分段，段名居中在各自那段条上方；当前段加粗、条用 `#FF5A1F` 往前走，讲完的段变白，没讲到的段暗灰。时间写整条片子的时间，配 `film_t0 / film_total`。只在讲解结构清楚的片子上用（rules L10）。
- 手里的道具颜色太跳会抢脸，正式录之前提醒换掉。
