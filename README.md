# ldd-video-edit

A reusable workflow for editing creator-led talking-head videos: transcript cleanup, shot planning, motion graphics, subtitles, assembly, and frame-by-frame checks. Supports 4:3 landscape and 9:16 vertical projects.

## Start here

1. Read `SKILL.md` for the end-to-end workflow and review gates.
2. Read `references/rules.md` before planning a new edit.
3. For hand-drawn MG, browse `templates/sketch/styles/preview/menu.html` and read `references/sketch-styles.md`.
4. Use `scripts/check_env.sh` to inspect local dependencies.

## Layout

- `scripts/` — transcription helpers, subtitle tools, video assembly, seam checks, and project scaffolding
- `kit/` — shared animation code
- `templates/` — reusable compositions and project templates
- `references/` — editing, animation, layout, and style guidance

Keep client briefs, project retrospectives, real user quotations, and machine-specific paths in private project workspaces—not in this reusable skill repository.
