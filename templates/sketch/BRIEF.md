# 素描本镜头制作说明（所有 worker 共用）

工程目录：`{{ANIM}}`
渲染器：`{{SK}}/scripts/sk_render.mjs`

> 主 Agent：派活前把下面带「填」的地方补上，再把**每个镜头的口播要点、时长 D、关键词出现时间**写进最后的「镜头清单」。

## 开工前必读
1. `kit/sk.js` —— `SK.page`（纸面 + 画风，必须调用）、`SK.shape / SK.line / SK.text`（按画风画形、画线、写字）、`SK.fillIn`（色块显出来）、`SK.draw`（一笔画）、`SK.write`（手写字从左往右）、`SK.show`、`SK.drop`（纸片/截图贴上来）、`SK.pop`、`SK.boil`（铅笔颤动，必须调用）、`SK.cam`（镜头推拉）、`SK.mount(tl, D)`（必须最后调用）
2. 参考镜头在 `_ref/`（填：这期指定哪一个当基准，例如 `_ref/steps-climb.html`）。结构、滤镜、配色、字体、小人画法照它来。**复制到 `anim/` 根目录再改**（脚本路径是 `kit/…`）

## 画风（硬性）
- 这期画风（填：pencil / journal / kraft / mono / chalk，见 `look/CHOSEN.md`）。每个镜头开头 `SK.page(sv,{style:'填'})`，照 `_ref/styles/填.html` 的写法
- 画面一律用 `SK.shape`（会按画风自动上色/错位/排线）、`SK.line`、`SK.text`（字体跟画风走）、`LDD.create`；颜色从 `SK.C[i]`、`SK.INK`、`SK.PAPER` 取，**不要把色值写死**。各画风的忌讳看 `references/sketch-styles.md`（例如 chalk 的字不写在排线色块上、mono 必须靠变形转场）
- 重音色每个镜头 2–4 处，不要满屏
- **人物**（规则 A10）：默认 `kit/stick.js`（`LDD.create`，线身体或色块身体由画风决定），动作照 `_ref/stick-sort.html`（IK 折线胳膊、捏纸时纸压在手前、松手从手的位置落、视线先到再伸手）。需要别的角色（机器人、小动物、色块小人）可以自己用 `SK.shape` 画，**和画面同一支笔**；不画项目当事人的写实肖像或专属 IP 形象，也不拿人物插画 PNG 拼代码胳膊
- **禁止**：章节小标题（「信号 01」「PART」）、角标（「官方数据」「来源」）、标题上方的装饰短横线/色条、色块标签胶囊、直尺画的笔直横线和坐标轴、发光、渐变、玻璃卡、英文小标签、平台 logo
- **画面上的数字和专有名词只能用下面镜头清单里写明的**。示意图不加别的数字，不编行业名、不编数据、不编功能名

## 版面
- 画布（填：竖屏 1080×1920 / 横屏 1440×1080），30fps
- 竖屏：内容只放 x 80–1000、y 200–1500，**y 1520 以下留给字幕**。横屏：重要内容在 y 920 以上
- 字号（竖屏）：主标题 80–100，数字 54–100，说明 32–44
- 文字不能被线穿过、不能互相压、不能被镜头推出画面。下划线离字底至少 12px
- 人物：举起的东西不能盖住头；胳膊不能被拉成直棍、不能穿过头；捏着东西时手和东西始终贴着；眼睛要看向手里或要拿的东西
- 被拿的东西从它该在的地方出来（信封里、手机里、桌上），不许中途淡入；render 里不要冻结时间

## 动作
- 线一笔一笔画，字从左往右写；**动作对准口播里关键词的出现时间**（相对镜头开头的秒数，可以提前 0.1–0.2 秒）
- 镜头可以推拉（`SK.cam`），任何时刻关键文字都在画面内
- 最后 0.5 秒画面完整、停稳；末帧就是全图
- 节奏轻快，像边讲边画
- 上下两个镜头讲同一件事时，用同一套坐标，下一镜第 0 帧接上一镜末帧

## 渲染与自检
```
cd {{ANIM}}
perl -e 'alarm 200; exec @ARGV' node {{SK}}/scripts/sk_render.mjs <镜头>.html _chk/<镜头> 0.5,2,4,<D-0.1>   # 先截静帧
perl -e 'alarm 900; exec @ARGV' node {{SK}}/scripts/sk_render.mjs <镜头>.html renders/<镜头>.mp4            # 再出片
```
- Chrome 偶尔启动卡死：alarm 会掐掉，重跑。**不要 pkill chrome**（别的 worker 也在渲）；自己同一时间只跑一个 render
- 静帧用 vision 看：重叠、出界、字被线穿过、字残缺、看不看得懂、可不可爱。**vision 给的坐标和"贴着/压住"判断经常前后矛盾**——有疑问就直接量像素（PIL 读颜色找边界）或放大裁图再看
- 出片后 `ffprobe` 确认时长 = D（误差 < 0.05 s）
- 文件名：镜头编号 + 内容，如 `m01-三个信号.html` → `renders/m01-三个信号.mp4`
- 截图静帧放 `_chk/`，交付前清掉
